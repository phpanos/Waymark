# Versioning

Bump the Waymark version with every new feature. Keep the version in `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, the `waymark` entry in `Cargo.lock`, `package.json`, and both root-package version fields in `package-lock.json` in sync. See [Windows alpha updates](docs/windows-updates.md) for the release procedure.
